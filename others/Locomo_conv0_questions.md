# LoCoMo

```text
locomo10.json
└── 样本数组（10 个）
    ├── sample_id          对话 ID，如 "conv-26"
    ├── conversation       两位说话者、分 session 的原始对话及时间
    ├── qa                 问题、答案、证据和类别
    ├── observation        按 session、说话者整理的观察事实
    ├── event_summary      按 session、说话者整理的事件
    └── session_summary    每个 session 的文字摘要
```
